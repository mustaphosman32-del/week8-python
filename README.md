# Week 6 Assignment: Safe Functions## Files- `safe_tools.py` - Contains three safe functions that handle division by zero, invalid number conversion, and missing dictionary keys.- `README.md` - Describes the assignment files and explains error handling in Python.## Why can the `if` check not catch `abc` on its own?An `if` statement can check a condition, but it does not automatically catch errors raised when converting text into an integer. Using `try` and `except ValueError` safely handles text such as `"abc"` that cannot be converted into a whole number.
