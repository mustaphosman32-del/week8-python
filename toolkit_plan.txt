
PERSONAL MINI-TOOLKIT — PROJECT PLAN

1. TOOLS

Tool 1: Simple Calculator
The calculator adds, subtracts, multiplies, and divides two numbers.

Tool 2: Number Guessing Game
The game lets the user guess a secret number between 1 and 10 until the correct number is guessed.

Tool 3: To-Do List
The to-do list allows the user to add, view, and remove tasks while the program is running.

Tool 4: Name Formatter
The name formatter asks for a name and displays it in uppercase, lowercase, and title case.
